# ALEXVID — Универсальный видеоплеер для Android

**ALEXVID** — современный Android-видеоплеер на базе движка **LibVLC**, созданный для воспроизведения локальных видео любых форматов и онлайн-потоков из интернета.

## Возможности

- **Все форматы видео и аудио**: MKV, MP4, AVI, MOV, FLV, WMV, WebM, TS, M2TS, 3GP, VOB, OGV, RMVB, H.264, H.265/HEVC, VP9, AV1, AC3, DTS и др. (аппаратное декодирование + программный FFmpeg-фолбэк).
- **Субтитры**:
  - Выбор встроенных дорожек субтитров (MKV/MP4 и др.).
  - Загрузка внешних файлов `.srt`, `.ass`, `.ssa`, `.vtt`, `.sub`, `.smi`.
  - Автопоиск файлов субтитров рядом с видео.
  - Синхронизация задержки субтитров (`±0.1с`, `±0.5с`), настройка размера и цвета шрифта.
- **Управление жестами**:
  - Свайп по левой части экрана вверх/вниз — **яркость**.
  - Свайп по правой части экрана вверх/вниз — **громкость (0–100% + усиление звука до 200%)**.
  - Горизонтальный свайп — **перемотка** с точным предпросмотром времени.
  - Двойной тап слева / справа — **−10 сек / +10 сек**.
  - Двойной тап по центру — **Пауза / Воспроизведение**.
  - Удержание пальца на экране — **ускорение 2.0x**.
  - Щипок двумя пальцами — переключение масштаба (**Вписать / Заполнить**).
  - Блокировка экрана от случайных нажатий.
- **Онлайн-видео и потоки (внешний плеер для интернета)**:
  - Поддержка **HLS (`.m3u8`)**, **MPEG-DASH (`.mpd`)**, **HTTP/HTTPS**, **RTSP**, **RTMP**, **UDP**, **MMS**, **IPTV (`.m3u`)**.
  - Расширенные настройки потока: `User-Agent`, `Referer`, размер сетевого буфера.
  - Избранные потоки и история просмотров с сохранением позиции.
  - Работает как внешний плеер: открывайте видео напрямую из браузера, Telegram и других приложений через **«Открыть с помощью → ALEXVID»** или **«Поделиться → ALEXVID»**.
- **Режим обзора фильмов (Зум, Покадровый просмотр, Скриншоты)**:
  - **Режим Зума (кнопка 🔍)** — полностью отключает обычные жесты плеера (яркость/громкость/перемотку), позволяя плавно приближать любую область кадра до **8.0x** двумя пальцами и смещать картинку одним пальцем (двойной тап — быстрый зум `3.0x` в точку / сброс).
  - **Покадровый просмотр (кнопка 🎞)** — точный шаг `−1 кадр` / `+1 кадр` по реальному FPS видео (удержание кнопки листает кадры подряд), быстрый шаг `±1с`, отображение таймкода с миллисекундами.
  - **Скриншоты (кнопка 📷)** — сохранение чистого PNG-кадра без интерфейса в альбом Галереи **`Pictures/ALEXVID`**. В режиме зума сохраняет именно выбранную приближённую область экрана (долгое нажатие на 📷 — полный кадр без обрезки).
- **Дополнительно**:
  - Выбор аудиодорожек, скорость `0.25x–3.0x`, режимы соотношения сторон, повтор, таймер сна, режим **Картинка в картинке (PiP)**, переключение ориентации.

## Сборка APK через GitHub Actions

При каждом коммите в `main` автоматически запускается workflow `.github/workflows/build-apk.yml`, который собирает готовые к установке APK-файлы:
- `ALEXVID-arm64-v8a.apk` — для современных Android-устройств (оптимальный размер).
- `ALEXVID-universal.apk` — универсальный APK для всех архитектур.

Готовые APK доступны во вкладках **Releases** и **Actions → Build ALEXVID Android APK → Artifacts**.
